# Dành cho người bán bản mẫu (chỉ chủ Trạm AI Việt đọc)

File này **không** gửi cho khách. Nó hướng dẫn cách chuẩn bị "link tạo bản sao" để khách cài dễ nhất.

## Làm 1 lần: tạo Sheet gốc

1. Tạo Google Sheet mới, đặt tên ví dụ **"Shop Tự Động – Bản mẫu"**.
2. Cài code theo mục **"Cách cài thủ công"** trong `HUONG-DAN-CAI-DAT.md` (dán Code.gs, index, admin).
3. **Không** chạy setup, **không** triển khai trên Sheet gốc. Để trống cho sạch.
4. Bấm **Chia sẻ → Bất kỳ ai có đường liên kết → Người xem**, chép link.
5. Đổi đuôi link từ `/edit...` thành `/copy`. Ví dụ:
   `https://docs.google.com/spreadsheets/d/ABC123/copy`

Ai mở link `/copy` sẽ thấy nút **Tạo bản sao**. Bản sao mang theo cả code, nên khách bỏ qua được bước dán code.

## Mỗi khi có người mua

1. Gửi khách: link `/copy` + file `HUONG-DAN-CAI-DAT.md` (hoặc bản PDF/Google Docs của nó).
2. Gói "Cài hộ": làm giúp khách Bước 2–6 qua UltraViewer/Zalo, mất khoảng 20 phút.

Có thể bán ngay trên shop Trạm AI Việt: tạo sản phẩm "Bản mẫu shop tự động", ô **Nội dung tự giao** điền link `/copy` + link hướng dẫn. Khách trả tiền là nhận ngay.

## Khi cập nhật code

1. Sửa code trong Sheet gốc (để khách mua sau nhận bản mới).
2. Gửi khách cũ file Code.gs/index/admin mới, kèm câu dặn: dán đè, bấm Lưu, rồi **Triển khai → Quản lý các lần triển khai → ✏ → Phiên bản mới**. Dữ liệu và tab CauHinh của khách giữ nguyên.

## Lưu ý

- Link `/copy` ai có cũng tạo được bản sao. Nếu muốn giữ chặt, chia sẻ Sheet gốc riêng cho Gmail từng người mua thay vì "Bất kỳ ai".
- Bản mẫu chỉ có sản phẩm mẫu trung tính. Không đưa danh mục tài khoản ChatGPT/Gemini dùng chung vào bản bán.
